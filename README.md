# MeetAI — AI Meeting Transcript & Action Tracker

A production-ready React (Vite) + Tailwind CSS frontend for an AI-powered meeting transcript and action item tracking platform.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Features

- Dark / Light mode with smooth transitions
- Responsive layout with collapsible sidebar and mobile drawer
- Authentication (login / register) with simulated auth
- Dashboard with 6 metric cards, recent meetings, and urgent tasks
- Meeting creation with rich-text paste and file upload
- AI processing simulation with step-by-step progress overlay
- Meeting list with search, filters, grid/table views
- Meeting details with tabbed AI results (summary, decisions, actions, transcript)
- Central action tracker with table and kanban views
- Toast notifications, delete confirmations, loading skeletons, empty states

## Tech Stack

- React 19 + Vite 8
- Tailwind CSS v4
- react-router-dom
- lucide-react
- react-quill-new
